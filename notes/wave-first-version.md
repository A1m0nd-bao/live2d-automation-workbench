# 挥手工作台第一版

在生产工作台左侧点击「挥手动作实验室」，或访问应用的 `#wave` 页面。输入 PSD 保持不变，所有分析和生成均在浏览器本地进行，无需部署视觉模型。

## 使用

1. 上传分层 PSD（不超过 100 MB，画布最长边不超过 4096）。必需图层：`handwear-l`、`handwear-r`、`action_02_wave_arms_only__handwear-l`、`action_02_wave_arms_only__handwear-r`。名称匹配用于定位素材，人物坐标每次重新分析。
2. 检查基础和抬手姿态的肩、肘、腕。拖动圆点或输入坐标校正。选择需要挥动的一侧，调整幅度。直臂肘部是比例估计，必须人工检查。
3. 点击「生成绑定与动作」。按素材透明轮廓生成网格，通过有效像素区域的路径分配上臂、前臂权重；肩部固定，手掌跟随前臂。手指保持原画形态。
4. 播放完整动作或小幅挥手循环。使用进度条检查抬手中段；可显示网格、保存当前帧。改动关节点后旧预览失效，必须重新生成。
5. 查看几何检查报告，人工检查露缝、重影、拉伸和遮挡，必要时回到关节校正。导出工程与动作包。

人物配置可保存、导入；手臂素材指纹不同会拒绝复用，防止不同人物误用坐标。

## 抬手过渡修正

基础手臂承担抬手主体，依据上臂和前臂的最大角度差计算素材切换：剩余旋转接近 30° 时开始混合，接近 8° 时完成；小角度素材按自身角度差缩放阈值。避免在固定中点将折叠手臂强行展开。权重读取采用双线性插值，直臂使用更宽的肘部权重过渡区域。预览和 CMO3 共用这些计算。两套手掌形状仍不同，切换时可能重影。

## 输出与边界

- `wave-model.cmo3`：带 `ParamActionWave` 关键形态的工程。
- `motions/wave_only.motion3.json`：小幅挥手循环。
- `motions/raise_wave_lower.motion3.json`：抬手、挥动、放下。
- `wave-profile.json`、`wave-qa.json`：人物标定、权重与检查结果。
- `preview/`：七个阶段的预览 PNG。

参数 0–1 为抬手，1–3 为一个挥手循环，1–0 为放下。预览直接插值导出的关键形态。

第一版不会补画中间素材、生成手指动作或自动判断美术质量。两套手臂姿态差异大时，抬手中段可能重影、局部变形。几何检查检测无效坐标、网格翻折、面积拉伸、肩部位移和循环连续性；若挥动阶段翻折较大，会尝试减小幅度。报告默认要求视觉验收，不等于自动通过。

**当前不直接输出可运行的 MOC3。** CMO3 写入与浏览器预览已验证；尚未在本轮使用 Cubism Editor 打开并原生编译验证。运行时交付仍需原生导出 MOC3 并注册动作。

## 实现位置

- `src/wave/psdWaveInput.js`：读取、名称验证、画布位置、素材指纹。
- `src/wave/armPoseAnalyzer.js`：透明轮廓、关节估计、沿有效像素区域的权重、配置校验。
- `src/waveRig.js`：人物配置解析、关键形态与动作曲线。
- `src/wave/wavePipeline.js`：网格绑定、导出包。
- `src/wave/waveValidator.js`：几何检查和幅度回退。
- `src/wave/waveRenderer.js`：关键形态预览。
- `src/WaveWorkbench.jsx`：上传、校正、播放、验收界面。

旧 V5 的固定标定已移至测试夹具，不参与生产人物分析。`scripts/build-wave-demo.mjs` 是早期 V5 演示脚本；新第一版以此工作台为入口。

## 验证

25 个相关测试通过：素材完整性、同名不同图形的缩放/平移/镜像、配置错配、肩与前臂权重、无效/翻折网格、循环、CMO3 关键形态、已有预检回归。Vite 构建通过。

使用 `00-cubism-import-free-v5.psd` 在 Chrome 验证上传、生成、播放、拖动校正、配置保存/导入、错配拦截、ZIP 导出；使用缺少替换手臂的 PSD 验证错误恢复。移动布局 390 像素宽度无横向页面溢出。

全项目 TypeScript 检查仍被本次未修改的 `src/live2dProMerge.ts:164` 阻塞：`opened` 不属于 `PsdLayer`。没有把构建成功当作全项目类型检查通过。

## 全程交接检查

新增 `armShape.js`：按当前 PSD 像素测量骨段横截面和手掌长度，在素材交接时匹配轮廓，肘部附近降低匹配强度以避免折叠区域影响测量。下层透明度改为 1−blend⁴，上层为 blend，减轻正常叠加造成的透明感；不代表轮廓外区域或手指空隙完全不透明。抬手采样间距为 1/32，挥动仍为 1/8，预览按实际关键值插值。导出与预览共用计算。

每次生成增加 5 秒、30 FPS、151 个时刻的数值采样，记录有限坐标、回归误差及最大顶点帧间位移。该记录不判定视觉自然程度。交接手指仍有重影，肘部仍存在局部翻折、拉伸提示，不能认为视觉验收通过。相关测试共 30 项通过，浏览器验证生成、播放和导出；未做 Cubism 原生打开和 MOC3 编译验证。
